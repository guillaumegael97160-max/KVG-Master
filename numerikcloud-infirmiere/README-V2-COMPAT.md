# NumerikCloud INF V2 + visuels V4

Base: code Java et tous les reglages de connexion WebView de la V2 fonctionnelle.

Images: intro_1 a intro_4 identiques a V4, plus ic_launcher original.

Nouvelle fonction: bouton rafraichir discret en haut a gauche, sans suppression des cookies ou de la session.

Les APK sont des versions debug. La signature de la V2 installee peut differer. Installer d'abord la version TEST a cote pour conserver la V2, ou desinstaller l'ancien paquet si vous choisissez la version originale et que la signature refuse la mise a jour.

Les donnees cloud sont gerees par le site Google Apps Script existant; cette application n'ajoute aucune gestion des informations medicales.
